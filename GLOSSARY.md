# Infra Finder

Infra Finder is a directory of open infrastructure services for research and scholarship, which helps people compare and choose among them.

## Language

**Solution**:
An infrastructure service listed in Infra Finder, belonging to a single provider and described by its solution properties.
_Avoid_: Service, product, tool, listing

**Provider**:
The organization that operates one or more solutions.
_Avoid_: Organization, vendor, owner

**Solution draft**:
A proposed set of changes to an existing solution, made on behalf of its provider and reviewed by Infra Finder administrators before it is applied. Approving a draft applies its changes and publishes the solution.
_Avoid_: Revision, edit, pending change

**Solution intake**:
A submission made on behalf of a provider that proposes a new solution, reviewed by Infra Finder administrators before the solution is created. Approving an intake creates an unpublished solution.
_Avoid_: Application, form, submission

**Solution property**:
A single piece of information that describes a solution, such as its mission, website, or categories.
_Avoid_: Field, attribute, question

**Solution completeness**:
Whether every required solution property has a value on a solution, solution draft, or solution intake. A draft or intake must be complete before it can be submitted for review or approved, and a solution before it can be published; any of them can be saved while incomplete.
_Avoid_: Valid, finished, filled out

**Solution property validity**:
Whether a solution property's value meets that property's constraints, such as a maximum length, a well-formed URL, or a limit on the number of choices. Validity concerns only the values given, so an incomplete solution, draft, or intake can still be valid.
_Avoid_: Complete, correct
